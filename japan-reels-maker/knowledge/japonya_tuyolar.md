# Japonya Tüyoları — Insider Veri Bankası

**Amaç:** Bu dosya LLM'in Reels metinlerini üretirken beslendiği tek gerçek kaynak.
Buraya yazdığın her satır tüyo/spesifik bilgi, üretilen `hook`, `aciklama` ve
`overlays`'de aynen veya paraphrase edilerek kullanılır. Uydurma yerine
"buraya yazılmışsa doğru" garantisi verir.

**Yazım kuralları:**
- Kısa, tek bilgi taşıyan cümleler yaz. Örnek: "Namba'daki 7-Eleven'da bavul dolabı var, 700 yen."
- Rakam/saat/fiyat varsa mutlaka yaz — LLM tahmin etmesin.
- Şüpheli/emin olmadığın bilgiyi buraya YAZMA. Boş kalsın.
- Kendi deneyimini "biz/ailemle" kalıbıyla yaz — LLM aynı dille alacak.
- Tag ekle satır sonuna: `#tokyo #ulasim` gibi. LLM filtrelemek için kullanır.

## Ek: Nasıl LLM'e Beslenir?

Bu dosyanın içeriği Dify workflow'unun LLM node'una **context** olarak veya
system prompt'a append edilerek gönderilir. Şu an:
- Dosya `knowledge/japonya_tuyolar.md` yolunda tutulur
- Değişiklik yapılınca `.venv/bin/python -m src.step3_dify` çalıştırılınca
  Python bu dosyayı okuyup Dify payload'una ek input olarak yollar
  (entegrasyon eklenecek — istersen bunu da yaparız)

**Şimdilik:** doldur, ben Dify'a besleme akışını sonra ekleyeceğim.
