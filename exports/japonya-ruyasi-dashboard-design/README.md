# Japonya Rüyası Dashboard — Tasarım Teslim Paketi

Bu paket, Instagram içerik üretme ve yayınlama ürünü için hazırlanmış
etkileşimli dashboard tasarımını başka bir geliştiriciye veya LLM'e devretmek
için hazırlanmıştır.

## Paket içeriği

- `index.html`: Yedi ekranın tamamını içeren çalışan, responsive prototip.
- `japan-editorial-grid.png`: Prototipte kullanılan özgün Japonya fotoğraf seti.
- `DESIGN-SPEC.md`: Görsel sistem, sayfa yapısı, bileşenler ve davranışlar.
- `LLM-HANDOFF-PROMPT.md`: Başka bir LLM'e doğrudan verilebilecek uygulama promptu.
- `screens/`: Masaüstü ve mobil referans ekran görüntüleri.

## Prototipi açma

Klasörü bir statik dosya sunucusuyla açın ve `index.html` sayfasına gidin.
Prototip framework bağımsızdır; tüm stil ve demo etkileşimleri tek HTML
dosyasındadır.

## Uygulama notu

Bu paket tasarım ve ön yüz davranışı içindir. Üretim sırasında demo verileri,
mevcut Japan Reels Maker API uçlarıyla değiştirilmelidir. Orijinal uygulamanın
çalışan paneli bu export paketine dahil edilmemiştir.
